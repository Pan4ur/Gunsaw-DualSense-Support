# Gunsaw DualSense Support

## Utilized DualSense capabilities

- Led - Pulse scarf colors
- Speaker - Cart engine / Heartrate when low hp / Locator* (works on Bluetooth but more stable with USB)
- Left linear actuator - Telekinesis weight feedback
- Right linear actuator - Shoot feedback
- Linear resonant actuators - Shoot / Engine / Damage feedback

## Gameplay

- Left stick - Move (50% tilt - slow move)
- Right stick - Aim

- L1 - Jump
- R1 - Kick

- L2 - Telekinezis
- R2 - Fire / Swap body

- L3 - Whine*
- R3 - Flashlight* / Locator*

- × - Ragdoll / Space
- ○ - Lctrl / Back
- □ - Enter(Exit) vehicle / Arsenal
- △ - Interact

- ↑ - Unarmed (H)
- ↓ - Pickup weapon (short tap) / Throw weapon (hold)
- ← - SlowMo
- → - Reload / Reform body

Touchpad:
- short - open chat*
- hold - show player list*
- swipe right/left - next/prev weapon

- Option - Pause / Esc
- Share - Restart level

## Menu

- D-pad / Left stick - select UI element
- × - Confirm
- ○ - Back

Level select:
- L1 / L2 - Select level
- × - Confirm
- □ - Select specie
- ○ - Back

Specie select:
- L1 / L2 - Select specie
- ○ - Back
- △ - Advanced info

Paused
- △ - Open MP UI*

## Chat*

- D-pad - select char
- × - Confirm
- L1 / R1 - Move cursor
- L3 / R3 - Change layout
- ○ - Back

Touchpad:
- Tap right side - Enter
- Tap left side - Backspace
- Scroll middle - scroll chat history

- △ - Space
- □ - Backspace

\* - [MP mod](https://github.com/Pan4ur/Gunsaw-Multiplayer-Mod) Features

## Installation

1. Download [Gunsaw](https://orsonik.itch.io/gunsaw-demo/purchase)
2. Extract the game to C:\Games\Gunsaw (or another folder)
3. Start the unmodified game once, then close it
4. Install [BepInEx](https://github.com/bepinex/bepinex/releases) into the game folder — the folder that contains the `Gunsaw.exe`
5. Download `GunsawDualsenseSupport.dll` from [releases](https://github.com/Pan4ur/Gunsaw-Dualsense-Support/releases)
6. Copy the `GunsawDualsenseSupport.dll` to ```<Gunsaw folder>\BepInEx\plugins\GunsawDualsenseSupport.dll```
7. Connect DualSence via Bluetooth or USB and enjoy
